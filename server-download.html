Tuff Client

A custom version of Tuff Client made to make joining the Yoshi's Minecraft server as easy as possible. The server is already added to the client's server list, so you don't have to enter the server address yourself.

Download Tuff Client

The client is a standalone HTML file. Your browser may ask whether you want to download or keep the file.

How to open it

After downloading the client, open your Downloads folder and find the Tuff Client HTML file.

  1. Download the Tuff Client using the button above.
  2. Open your Downloads folder and find the downloaded HTML file.
  3. Double-click the file. It should open in your web browser.
  4. Wait for Tuff Client to load. You can then select the Yoshi's server from the server list.

If Windows asks which program should open the file, choose your normal web browser, such as Chrome, Edge, or Firefox.

What's included?

This version has been modified specifically for the Yoshi's server. The server is pre-configured in the client, making it easier to get into the server without manually adding an address.
