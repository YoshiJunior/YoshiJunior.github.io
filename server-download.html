Yoshi's Minecraft

Download the official FPMS Eaglercraft Server!

This is a custom Tuff Client made for Yoshi's Minecraft server. The server is already added for you, so you can download the file and start playing without entering the address yourself.

Download Tuff Client Standalone HTML file, ready to open in your browser.
Server already configured, works in Chrome, Edge, Firefox, and other modern browsers.

How to open the client

  1. Download Tuff Client.
  2. Open your Downloads folder.
  3. Find the downloaded .html file.
  4. Double-click it to open it in your browser.
If Windows asks which app to use, choose your normal web browser such as Chrome, Edge, or Firefox.

Why use this client?

  • Your server is already in the server list.
  • No need to manually type the server address.
  • Everything is contained in one HTML file.
  • You can open it directly after downloading.
